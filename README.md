# 量化研究 · quant-research

> 一个**从零自建**的 A 股量化研究系统：原始数据自采、模拟盘撮合自建、本地模型自训，每一步决策留痕，每一次优化进 git。

- 仓库：<https://github.com/YRZ-GUANGNAN/quant-research>
- 目标市场：A 股 · 沪深300 成分股 · 日频
- 资金性质：**模拟盘**，不接真实券商，不构成投资建议

## 在做什么

1. **调研**当前开源量化工具生态（vectorbt / backtrader / qlib / vnpy / rqalpha …），判断「哪个真正好用、按现状怎么用」→ `docs/research/`。
2. **自建数据层**：直连东方财富原始 HTTP 接口，不依赖 akshare 这类随时变更的中介库 → `quant/data/`。
3. **自建模拟盘**：T+1、涨跌停不可成交、停牌、佣金/印花税/过户费/滑点、100 股整手，全部显式建模 → `quant/engine/`。
4. **演练策略**：单因子 → 多因子 → 机器学习 → 风控叠加，逐轮迭代，每轮给出回测数字与失败原因 → `docs/journal/`。
5. **决策留痕**：每个关键抉择前先写 10 条**攻击性自问**（专挑自己结论的漏洞），再决定「继续 / 回退 / 停止」→ `docs/decisions/`。
6. **本地量化模型**：把最优流程固化成可复跑的模型产物，而不是一次性脚本。

## 快速开始

```powershell
python -m pip install -r requirements.txt

# 1. 抓数据（沪深300 成分股 + 基准指数）
python scripts/fetch_data.py --index 000300 --start 2018-01-01

# 2. 回测
python scripts/run_backtest.py --strategy momentum

# 3. 模拟盘日更
python scripts/run_paper.py
```

## 关键假设与已知偏差

| 项 | 处理方式 | 风险 |
|---|---|---|
| 复权 | 个股前复权（含分红再投），指数不复权 | 与真实成交价存在价差 |
| 幸存者偏差 | 宇宙 = **当前**沪深300 成分股 | 历史成分无法还原，收益被高估 |
| 成交价 | t 日收盘算信号，t+1 开盘成交 | 未建模集合竞价冲击 |
| 涨跌停 | 按原始涨跌幅判断，封板不成交 | 实际排队可能部分成交 |
| 成本 | 佣金万2.5（低5元）+ 卖出印花税0.05% + 过户费0.001% + 滑点5bp | 大资金冲击成本更高 |
| T+1 | 当日买入次日才可卖 | 与真实规则一致 |

## 决策机制

见 `docs/decisions/`。每份决策文档必须包含：

1. 决策问题；
2. **10 条攻击性自问**（例如「如果这个因子只是 2020 年抱团的产物呢？」）；
3. 逐条回答与证据；
4. 判断：**继续 / 回退 / 停止**，以及改变判断的触发条件。
