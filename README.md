# 量化研究 · quant-research

> 一个**从零自建**的 A 股量化研究系统：原始数据自采、模拟盘撮合自建、本地模型自训；
> 每个关键决策前写 **10 条攻击性自问**，每次优化提交 git，最终给出**诚实的结论**——包括失败的部分。

- 仓库：<https://github.com/YRZ-GUANGNAN/quant-research>
- 覆盖市场：A 股（主线）、美股、港股、加密货币（稳健性检验）
- 资金性质：**模拟盘**（100% 虚拟资金），不接真实券商，不构成投资建议

---

## 一句话结论

**这套因子（流动性溢价 + 反转 + 小成交额）在 2018-2022 年有效（多相位年化超额 +22.2%，IR 1.28），
2023-2024 衰减到 +6.0%±5.0%，2025 年以后没有超额（-0.6%±5.0%）。**

项目交付的不是「赚钱策略」，而是：
1. 一条**可复现、可证伪**的量化研究流水线（27 个单元测试 + 全链路可运行）；
2. 一个**可运行的本地模型**（`models/model_v2.json` 相位共识 + 每日目标组合生成器）；
3. 一个**诚实的负面结论**与因子衰减证据（`docs/journal/0002`）。

> 换句话说：这次研究的价值在于「知道它什么时候失效」，而不是「找到了 alpha」。

## 核心结果

### 策略对照（训练期 2018-2022，基准年化 -1.12%）

| 预设 | 年化 | 夏普 | 最大回撤 | 信息比率 | 换手 |
|---|---|---|---|---|---|
| momentum | 19.30% | 0.684 | -45.2% | 0.901 | 12.5x |
| reversal | 16.19% | 0.646 | -33.7% | 0.921 | 19.9x |
| multi（先验拍方向） | 14.02% | 0.578 | -38.3% | 0.762 | 16.1x |
| **ic_tilt（IC 驱动，最终模型）** | **24.99%** | **0.919** | **-28.2%** | **1.314** | 14.0x |

### 多相位稳健性评估（`scripts/evaluate.py`，4 个调仓相位）

| 分段 | 年化 | 年化超额 | 信息比率 | 结论 |
|---|---|---|---|---|
| 训练 2018-2022 | 21.12% ± 4.61% | +22.23% | 1.28 | 有效（含样本内偏差） |
| 验证 2023-2024 | 6.62% ± 5.04% | +5.99% | 0.60 | 弱成立，信噪比≈1.2 |
| 样本外 2025- | 2.61% ± 5.01% | **-0.63%** | -0.07 | **无超额，停机** |

### 为什么必须多相位

同一策略只把调仓相位错开 5 个交易日，2023-2024 的验证期年化在
**-0.29% ~ +13.24%** 之间跳动（标准差 5.04%，与均值同量级）。
→ **单窗口回测的结论大部分是路径噪声**，这是本项目最重要的方法论结论。

## 创新：把「相位运气」从制度上消灭

既然发现「换 5 天结论就变」，那就做一个**不依赖相位**的组合。

### A. 相位不变组合（Phase-Invariant Ensemble）✅

同时运行 4 个错开 5 天（0/5/10/15）的虚拟子策略，各自在自己调仓日更新持仓；
主组合**每天**用子策略的**共识**校准：权重加总 → 只留共识 top-30 → 归一化。
被多个相位同时选中的股票权重更高，单一相位的运气最多占 1/4。
撮合层的 15%/20% 无交易带抑制换手。

| 分段 | 基线（单相位） | 相位不变组合 | 变化 |
|---|---|---|---|
| 训练 2018-2022 | 21.12% ± 4.61% | **27.30% ± 1.24%** | 标准差 ↓73% |
| 验证 2023-2024 | 6.62% ± 5.04% | **6.71% ± 0.53%** | 标准差 ↓90% |
| 样本外 2025- | 2.61% ± 5.01% | **3.01% ± 1.06%** | 标准差 ↓79% |
| 信息比率（训练） | 1.283 ± 0.219 | **1.560 ± 0.055** | 显著更稳 |
| 年化换手 | 13.8x | 16.7x | 成本 +21% |

**它的价值不是变出 alpha，而是让结论可复现**：无论从哪个调仓日开始，
得到的都是同一个结论（而不是 -0.3% 到 +13% 的抽奖）。
已采纳为模型 v2（`models/model_v2.json`）。

### B. 因子自检闸门（IC Gate）❌

让策略用自己最近 60/120 期滚动 Rank IC 判断「我是不是失效了」，失效则降仓。

| 配置 | 训练 | 验证 2023-2024 | 样本外 2025- |
|---|---|---|---|
| 基线 | 21.12% | 6.62% | 2.61%（超额 -0.63%） |
| 激进（w60 清仓） | 9.95% | **-8.89% ± 8.10%** | 6.65% |
| 保守（w120 半仓） | 15.31% | 5.79% | **8.37%（超额 +5.13%）** |

硬结论：**激进版失败**（把正收益做成 -8.9%，IC 噪声导致频繁误杀）；
保守版证据分裂（好行情降仓、坏行情避险），且样本外已在上一轮被看过一次，
**不能用「OOS 变好」证明它有效** → 登记为待验证假设，不进模型。
详见 [决策 0006](docs/decisions/0006-innovations-phase-ensemble-and-ic-gate.md)。

> 两个创新的对照说明：A 成功是因为它修的缺陷（相位噪声）**可观测、可证伪**；
> B 失败是因为它想修的问题（因子何时失效）**不可直接观测**，代理指标噪声太大。
> 创新不是复杂度竞赛，是「缺陷 ↔ 机制」的精准匹配。


### 成本敏感性（ic_tilt，验证期单相位）

| 滑点 | 年化 |
|---|---|
| 0 bp | 10.07% |
| 5 bp | 9.68% |
| 10 bp | 8.97% |
| 20 bp | 8.03% |

策略能承受 20bp 滑点；真正的杀手是因子衰减，不是交易成本。

### 跨市场对照（同一引擎、同一因子）

| 市场 | 年化 | 基准年化 | 超额 | 夏普 | 最大回撤 |
|---|---|---|---|---|---|
| 美股（60 只） | 18.67% | 14.34% | +4.34% | 0.99 | -31.4% |
| 港股（59 只） | 6.85% | -3.27% | +10.11% | 0.41 | -48.3% |
| 加密（17 只） | 17.17% | 15.01% | +2.16% | 0.51 | -77.6% |

**方向一致性检验**：`vol_20` 在美股 IC +0.021、港股 IC -0.019 —— **方向相反**，
说明因子有效性依赖市场制度，不能把一个市场的结论套到另一个市场。
（跨市场只比方向，不比收益；静态名单存在幸存者偏差。）

## 快速开始

```powershell
python -m pip install -r requirements.txt

# 1) 抓数据：指数 + 时点成分股（BaoStock），A 股日线（腾讯，558 只约 72 秒）
python scripts/fetch_data.py --start 2018-01-01
python scripts/fetch_tx.py --workers 8

# 2) 因子 IC 诊断
python scripts/run_backtest.py --strategy ic --horizon 5

# 3) 回测 + 分段绩效
python scripts/run_backtest.py --strategy ic_tilt --segments

# 4) 多相位稳健性评估（关键！）
python scripts/evaluate.py --strategy ic_tilt --phases 0,5,10,15

# 5) 多市场对照
python scripts/fetch_market.py --market all
python scripts/run_multi.py --strategy momentum --ic

# 6) 模拟盘日更
python scripts/run_paper.py --fetch

# 7) 生成今日目标组合与调仓指令 + 导出模型
python scripts/predict.py --export
```

## 数据源与已知偏差

| 项 | 处理方式 | 风险 |
|---|---|---|
| A 股行情 | 腾讯前复权日线（BaoStock 限流后切换） | 无真实成交额/换手率，`amount≈close×volume` |
| 时点成分股 | BaoStock 半年快照（2018-2026） | 快照日与真实调样日之间数天误差 |
| 复权 | 个股前复权，指数不复权 | 前复权每日重算，历史不可完全复现 |
| 涨跌停 | 开盘价 vs 前收判断，封板不成交 | 实际排队可能部分成交 |
| 交易成本 | 佣金万2.5（低5元）+ 卖出印花税0.05% + 过户费0.001% + 滑点5bp | 大资金冲击成本更高 |
| 非 A 股 | Yahoo 10 年数据，静态名单 | 幸存者偏差，未剔除 |
| 样本外 | 2025+ 已泄露一次（见 journal 0002） | 后续不再用其调参 |
