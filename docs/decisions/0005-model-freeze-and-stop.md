# 决策 0005 · 模型选择与「停止优化」

- 日期：2026-10-22
- 状态：生效
- 前置：决策 0002（评估协议）、0004（多市场）
- 触发：多相位评估发现「单窗口回测结果不可信」

## 关键事实（多相位评估，4 个调仓相位）

策略 `ic_tilt`（amihud 流动性溢价 + 反转 + 小成交额，固定权重）：

| 分段 | 年化 | 年化超额 | 夏普 | 信息比率 | 标准差（年化） |
|---|---|---|---|---|---|
| 训练 2018-2022 | 21.12% | 22.23% | 0.84 | 1.28 | ±4.61% |
| 验证 2023-2024 | 6.62% | 5.99% | 0.39 | 0.60 | ±5.04% |
| 样本外 2025- | 2.61% | **-0.63%** | 0.22 | -0.07 | ±5.01% |

同一策略只把调仓相位错开 5 个交易日，验证期年化就能从 -0.29% 跳到 +13.24%。
这直接推翻了「单窗口验证通过」的结论。

## 10 条攻击性自问

**Q1. 训练期超额 22%，但标准差 4.6%，这算有效吗？**
A：算「方向上有效、幅度不可信」。标准差/均值 ≈ 0.22，说明 4 个相位都为正，
但具体数值不能拿去预期未来。报告只写区间，不写单点。

**Q2. 验证期均值 +6%，标准差 5%，该判「通过」还是「不通过」？**
A：按决策 0002 的「单轮改进 < 1% 年化视为噪音」不适用这里，因为这是策略级评估。
我的判断是**弱通过**：均值正、但信噪比约 1.2，不足以支撑继续调参；
只能作为「假设仍然成立」的证据，不能作为「可以加杠杆」的证据。

**Q3. 样本外 2025- 超额 -0.63%，按协议该停机吗？**
A：**该停机**。协议写的是「OOS 失败要归因清楚，不许刷数字」。
归因结论：因子在 2023 后衰减，IC 从训练期的 amihud 0.275/rev 0.116
降到全样本的 0.190/0.114——衰减是真实的，不是 bug。

**Q4. LightGBM 比线性合成好在哪？还是只是过拟合得更花哨？**
A：在 300 只 × 8 年的数据量上，非线性模型极易学到噪声。
我的预期是它**不会**显著优于线性（样本量不够），
所以即使它回测更好看，也不会采用——除非它在验证期的**多相位标准差**更小。
（本轮因训练耗时，LGBM 的完整多相位评估未完成，已列为下一轮第一优先级。）

**Q5. 因子衰减是因为市场变了，还是因子被套利掉了？**
A：两者都可能，无法用本数据区分。可观测事实：2023 后 A 股小市值/流动性溢价仍存在，
但反转因子的 IC 明显下降。判断：**部分是结构性变化（量化资金增加），部分是因子拥挤**。
不做更细归因，因为数据不足以支持。

**Q6. 年化换手 13.8 倍，成本吃掉多少？**
A：滑点从 0 加到 20bp，年化从 10.07% 降到 8.03%（验证期单相位）。
按多相位均值，成本敏感性方向一致：策略能承受 20bp 滑点，成本不是主要杀手。
真正的杀手是**因子失效**，不是成本。

**Q7. 如果停机，这个项目交付什么？**
A：交付三样东西：
1. **可复现的研究流水线**（数据→因子→模拟盘→评估，全部有测试与文档）；
2. **一个诚实的结论**：该因子组合在 2018-2022 有效、2023 后衰减、2025 起无超额；
3. **一个可运行的本地模型**（ic_tilt 权重 + 每日目标组合生成器），
   供模拟盘继续验证，而不是供实盘赚钱。

**Q8. 模拟盘该用哪个策略上线？**
A：用 `ic_tilt`（固定权重、可解释、无过拟合风险），
**不用** LightGBM（样本不足、黑箱、验证未完成）。
模拟盘定位是「流程演练 + 持续观察因子是否恢复」，不是「赚钱」。

**Q9. 消除了幸存者偏差后，还剩哪些偏差？**
A：仍有三条：① 前复权数据每日重算导致不可完全复现；
② 涨跌停用「开盘价 vs 前收」近似，实际排队可能部分成交；
③ 腾讯数据缺真实成交额/换手率，用 close×volume 近似，流动性因子有误差。
三条都写进 README 的偏差表，不隐藏。

**Q10. 下一个最该试的假设是什么？**
A：按优先级：
1. **降低换手**（20 日→40 日调仓 + 缓冲区），看成本后收益是否改善；
2. **加入风控择时**（基准跌破 200 日均线时降仓），看回撤能否从 -29% 压到 -20%；
3. **换宇宙**（中证500），验证 amihud 溢价是否在更大池子里更强。
不做的事：继续微调因子权重去拟合 2023-2024（这就是过拟合）。

## 判断结果

| 决策 | 结论 |
|---|---|
| 继续调参？ | **停止**（触发停机规则：OOS 无超额） |
| 上线模型 | `ic_tilt` 固定权重 |
| LightGBM | 保留代码，不采用（待多相位验证） |
| 模拟盘 | 用 ic_tilt 继续跑，观察因子是否恢复 |
| 下一轮 | 降换手 / 加风控 / 换宇宙（三选一先做降换手） |

**本决策的核心不是「找到了 alpha」，而是「知道什么时候该停」。**
