# 决策 0007 · 把「稳定」定义成可证伪的数字

- 日期：2026-10-23
- 状态：生效
- 触发：目标要求「实现稳定为止之前，不间断继续自我优化」

## 为什么必须先定义「稳定」

「优化到稳定为止」如果不定义稳定，就是一个可以无限进行下去的自我欺骗循环：
每改一次参数，总能找到某个窗口更好看。所以先把稳定写成 7 条硬指标，
全部满足才算「稳定」，并规定**不许修改指标去迁就结果**（要改必须另写决策文档）。

## 稳定标准（S1–S7）

以**多相位评估**（4 个相位：0/5/10/15）为准，全部基于模型 v2 的相位不变组合：

| # | 指标 | 阈值 | 理由 |
|---|---|---|---|
| S1 | 跨相位年化标准差（全期） | ≤ 1.5% | 相位不变组合当前 ≈1.2%，必须守住 |
| S2 | 年化换手率 | ≤ 15x | 当前 16.7x，成本 0.1%/边 → 15x 约 1.5% 年化成本 |
| S3 | 全期最大回撤 | ≤ 28% | 当前约 30%，超过 30% 人拿不住 |
| S4 | 验证期 + 样本外年化均值 | > 0 | 当前 6.7% / 3.0%，已达标 |
| S5 | 滚动 1 年年化为正的比例 | ≥ 60% | 「任意时点买一年」多数时候不亏 |
| S6 | 最长水下时长 | ≤ 400 交易日 | 约 1.6 年，再长说明策略失效期太长 |
| S7 | 最好一年占正收益之和的比例 | ≤ 40% | 防止「全靠某一年」的假稳定 |

**当前状态（v2）**：S1 ✅ / S2 ❌(16.7x) / S3 ❌(≈30%) / S4 ✅ / S5 ❓ / S6 ❓ / S7 ❓
→ 本轮要做的是把 S2（换手）和 S3（回撤）压进阈值，同时不破坏其他项。

## 10 条攻击性自问

**Q1. 这些阈值是不是为了迁就当前模型拍出来的？**
A：部分是。S2=15x、S3=28% 就是「当前值稍微收紧」——但这正是「优化」的定义：
在不破坏已达成项的前提下，把未达标项推进阈值内。阈值本身参考了行业常识
（换手 15x ≈ 1.5% 年化成本、回撤 30% 是多数人心理上限），不是纯拍脑袋。
若某阈值无法达成，必须另写决策说明原因，不许静默放宽。

**Q2. 为什么用滚动 1 年正收益比例，而不是夏普？**
A：夏普假设收益近似正态、且对路径不敏感；而「稳定」关心的恰恰是「任意时点进入会不会亏」。
滚动 1 年正收益比例直接回答这个问题。夏普仍保留为辅助指标。

**Q3. 最大水下时长 400 天会不会太宽松？**
A：A 股熊市 1.5 年很常见（2018、2022 都是），400 天已经是「能不割肉」的极限。
再严会导致必须在熊市强行交易，反而伤害收益。

**Q4. 「最好一年占比 ≤40%」能防住过拟合吗？**
A：只能防「收益集中在单一年份」这一种过拟合，防不了全部。
它是个廉价的健壮性检查，不替代样本外与多相位评估。

**Q5. 换手压到 15x 以下，会不会把 alpha 也压掉？**
A：可能。这正是要实测的：如果降换手后验证期/OOS 年化跌超过 2%，说明 alpha 依赖高频换手，
那就得重新权衡（S2 与 S4 冲突时，优先 S4，但必须在文档里写明取舍）。

**Q6. 回撤压到 28% 以下，会不会变成「熊市空仓、牛市追高」的择时策略？**
A：有这个风险。择时（200 日均线）在 A 股历史上能降回撤，但也常在 V 型反转时踏空。
所以要用多相位 + 分段评估：如果降回撤的代价是 OOS 收益转负，就不采纳。

**Q7. 7 条标准里有没有可能互相冲突？**
A：有。S2（低换手）与 S4（正收益）冲突最可能；S3（低回撤）与 S4 也可能冲突。
冲突时的优先级：S4 > S1 > S3 > S2 > S5/S6/S7。
理由：没有正收益的稳定性没有意义。

**Q8. 「稳定」之后还继续优化吗？**
A：目标写的是「实现稳定为止」，所以达到 S1–S7 即视为本轮目标完成；
之后应停止调参，转入「监控与再验证」模式（新数据进来后重新检查指标是否仍满足）。

**Q9. 会不会为了达标而把参数调到过拟合？**
A：会，所以所有实验只允许在训练期（2018-2022）做选择；
验证期（2023-2024）只看一次结论；2025+ 样本外已泄露，只作参考不作选择依据。
本轮新增的实验（换手/回撤优化）只允许用训练期指标做决定。

**Q10. 如果这一轮怎么调都达不到 S2/S3，怎么办？**
A：按顺序尝试：① 延长调仓周期；② 共识变化阈值；③ 波动率目标；
④ 均线择时。四条都试完仍不达标，就写「稳定标准不可达」的决策，
说明是模型上限问题而非调参问题——这同样是一个有效结论。
