# 迭代日志 0031 · ic_tilt2 评估：验证/OOS 改善，但全期收益下降（暂不替换）

## 实验

`ic_tilt2` = v3 权重微调 + 三个新因子（vol_price_corr_60 -0.15、intraday_20 -0.10、overnight_20 +0.05）。
评估：4 相位 + 4 成员相位共识，k40/reb35。

## 判定：暂不替换，保留为候选

**支持 ic_tilt2 的证据**：
- 验证期超额 5.99% → **8.42%**（+2.4pp）；
- 样本外超额 -0.63% → **+0.18%**（首次转正，尽管幅度小）；
- 样本外回撤 -19.78% → **-17.07%**，OOS 夏普 0.223 → 0.298；
- S1–S7 仍全过。

**反对的证据**：
- 全期年化 **-0.81pp**（14.77% vs 15.58%），超过「1% 以内视为噪音」的边界；
- 换手 +1.16x（成本约 +0.12pp/年）；
- 验证期标准差从 ±0.53 放大到 ±2.42（4 相位间波动变大）；
- 样本外已被看过一次，+0.18% 的超额不能当独立证据。

**结论**：这是「用全期收益换验证/OOS alpha」的交换，不是全面改进。
按评估协议，**不满足「不破坏收益」的替换标准**，因此：
1. 模型保持 v3（固定权重）；
2. `ic_tilt2` 记为候选，等 2027+ 新样本外数据再检验；
3. 不根据 OOS 的 +0.18% 调权重（那是样本外调参）。

## 反思

新因子确实捕捉到了 amihud 衰减后的部分信息（验证期 +2.4pp 超额是真实的），
但代价是全期收益下降——说明**因子之间是替代而非叠加关系**：
加入微观结构因子后，组合整体更偏反转/日内，牺牲了长期动量的部分收益。
这提醒：因子增强不是「加更多因子更好」，而是「换一组风险暴露」。
