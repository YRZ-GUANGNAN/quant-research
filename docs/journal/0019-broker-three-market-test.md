## 关键发现

1. **下单链路已完全打通**：CLI 的「预览 → confirmation_code → `--execute` 提交」流程可用，
   这是券商侧的人工确认机制（每次订单一个一次性码）。
2. **港股可真实成交**：限价 385 实际成交 381.60（优于限价），说明撮合是真实的模拟撮合。
3. **A 股不可交易**：报 `China Connect` 不支持——该委托方式/账户没有沪深港通交易能力。
   因此 **A 股目标组合不能直接下发到 Longbridge**，只能继续走本地引擎。
4. 账户资产：USD 2,020,585.42，总现金 2,015,134.07，可用现金 999,783.00（部分被冻结）。

## 这对系统的意义

模型 v4 的三个袖子（A 股 60% / 美股 30% / 港股 10%）恰好可以拆开执行：

| 袖子 | 执行场所 | 状态 |
|---|---|---|
| A 股（60%） | 本地引擎（T+1/涨跌停/费用） | ✅ 已运行 |
| 美股（30%） | Longbridge 模拟盘 | ✅ 可下单（休市时排队） |
| 港股（10%） | Longbridge 模拟盘 | ✅ 实测成交 |

这就是天然的**双轨对照**：同一模型的不同袖子在不同撮合环境里跑，可以比较
「本地引擎假设」与「券商真实撮合」的滑点、成交价、成交率差异。
