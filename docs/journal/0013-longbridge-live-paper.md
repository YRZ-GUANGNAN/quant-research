## 2. 首次「真实报价 + 本地引擎」模拟盘实操

既然实时报价可用，就用它执行了 10-22 收盘生成的 40 只挂单：

```
[paper_live] 待执行 40 只 -> 拿到 40 只实时报价
成交：买入 1 笔、卖出 0 笔，费用 5.11 元
市值：3,492,961 -> 3,489,370 元
持仓：41 只；pending 已清空
```

为什么只有 1 笔成交：目标组合与当前持仓高度重合（40 vs 41 只），
撮合层有 15%/20% 无交易带，只在偏离足够大时才动手 —— 这正是设计意图，不是故障。

口径说明：用**盘中实时价**代替「次日开盘价」撮合，与真实集合竞价会有差异；
broker 规则（T+1、整手、涨跌停、佣金/印花税/滑点）仍走本地引擎，未打折扣。
