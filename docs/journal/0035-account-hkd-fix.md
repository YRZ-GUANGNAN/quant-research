# 迭代日志 0035 · 账户问题诊断：换汇不可编程，两条路

## 事实（已实测）

| 检查 | 结果 |
|---|---|
| HKD 可用现金 | **-3,042,337.81** |
| SGD 可用现金 | 1,000,000.00 |
| USD 可用现金 | 258,426.10 |
| Longbridge SDK 换汇方法 | **无**（TradeContext 方法列表无 exchange/convert/currency） |
| CLI 换汇命令 | **无**（只有 `exchange-rate` 汇率查询） |

结论：**API 层无法自己做货币兑换**。负港币只能靠「App 内换汇」或「卖出港股」解决。

## 两条路

### A. 你在 App 换汇（推荐，2 分钟，不动持仓）
- 用 SGD 1,000,000 里的约 **550,000 SGD** 换成约 3.2M HKD（SGD/HKD ≈ 5.85）；
- 港币转正后，脚本的门控会自动恢复港股下单（`HKD <= 0 跳过` 的条件解除）；
- 持仓、模型组合都不变。

### B. 我卖出港股补正（已备好工具，但代价大）
`scripts/lb_fix_hkd.py` dry-run 计划（10 笔，约 3.19M HKD）：

```

sell 386.HK 112000  约 502,320
sell 3.HK    70000  约 499,310
sell 322.HK  40000  约 493,000
```

**代价**：卖掉约 79% 的港股持仓（4.04M → 0.85M），打乱模型目标组合，产生交易成本。

## 建议

选 **A**：换汇不改变持仓与模型，只是把融资方式从「港币透支」换成「自有港币」。
选 **B** 只在你不想动 App 时使用——我已把工具写好，一条命令可执行。

## 工程

- 新增 `scripts/lb_fix_hkd.py`：dry-run 默认，`--execute` 才真正卖出；
- 港股门控已存在（HKD ≤ 0 自动跳过下单），A 方案换汇后自动恢复。
