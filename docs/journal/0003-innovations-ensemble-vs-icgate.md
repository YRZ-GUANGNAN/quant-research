# 迭代日志 0003 · 两个创新：一个成功，一个失败（2026-10-23）

## 这轮做了什么

| 实验 | 动机 | 结果 |
|---|---|---|
| 相位不变组合 | 上一轮发现「单相位结论是路径噪声」 | **成功**：标准差 ↓73~90%，均值不变 |
| 因子自检闸门 | 上一轮发现「因子 2023 后衰减」 | **失败**：激进版把验证期做成 -8.9% |

## 创新 A 的成功细节

中期版本（主组合每 20 天执行）失败了一半：标准差只从 5.04% 降到 4.75%——
因为主组合自己的调仓相位又引入了新的路径噪声。
改成**每天校准 + 子策略共识 + 撮合无交易带**后，标准差骤降到 0.53%。

教训：**「消除相位依赖」必须消除所有相位，包括你自己引入的那个。**
这是本轮最有价值的工程洞察——不是想出一个新点子，而是把一个点子做对。

## 创新 B 的失败细节

`ICGate` 的设计假设是「滚动 IC 能预测因子失效」。实测：
- 60 期窗口：验证期 -8.89% ± 8.10%（好因子被误杀）
- 120 期窗口 + 半仓：训练 21%→15%，OOS +8.4%（坏行情避险，好行情错过）

失败原因不是实现，而是**统计量本身的信噪比不够**：
IC 的自相关很低，60-120 期均值仍不足以区分「因子衰减」与「短期噪声」。
这解释了为什么业界很少直接用 IC 做仓位开关——不是没人想到，是这个信号太弱。

## 诚实记录：一个反例陷阱

保守版在 OOS 上超额 +5.1%，很容易被包装成「成功」。
但 OOS 我在上一轮已经看过一次（journal 0002），
在同一份 OOS 上反复挑参数 = 变相在 OOS 上调参。
所以本轮的判定是「证据分裂、不采纳」，并把它登记为待验证假设（等 2027+ 新数据）。
**能抵抗「OOS 好看」的诱惑，比做出好看的结果更重要。**

## 当前模型的最终形态（v2）

```
模型名  : ic_tilt_ensemble_v2
选股    : amihud + 反转 + 小成交额（训练期 IC 定符号，不调参）
组合    : 4 相位共识（0/5/10/15 天），每日校准
交易    : T+1、100 股整手、涨跌停不可成交、佣金/印花税/滑点
评估    : 多相位均值±标准差
结论    : 训练 27.3%±1.2%，验证 6.7%±0.5%，OOS 3.0%±1.1%（超额 -0.2%）
```

## 反思

这轮最大的收获不是那个成功的创新，而是**验证了「创新必须对着已证实的缺陷设计」**：

- A 成功，因为缺陷（相位噪声）是可观测、可量化的；
- B 失败，因为缺陷（因子何时失效）是不可直接观测的，只能靠噪声极大的代理指标。

下次再想「大胆创新」时，第一个问题应该是：
**我要修的这个缺陷，能被数据直接证伪吗？** 不能，就先别做。
