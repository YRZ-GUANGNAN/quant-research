# 迭代日志 0023 · 购买力预检与「HKD 负现金」根因（2026-10-23）

## 本轮改动

下单前增加**按币种的购买力预检**（`cash_by_ccy()` + 预算取 min）：

```
[cash] USD 可用 258,426.10 / HKD 可用 -3,042,337.81
[budget] 美股 253,257.58 USD（预检后）；港股 -2,981,491.05 HKD（预检后）
[plan] 订单 0 笔
```

预检生效后港股直接规划 0 笔，不再把整批订单丢给券商被拒。

## 新发现：账户是「多币种 + 港币透支」

| 币种 | 可用现金 |
|---|---|
| USD | 258,426.10 |
| SGD | **1,000,000.00** |
| HKD | **-3,042,337.81**（负） |

这解释了此前 17 笔港股被拒：港股买入把 HKD 现金打成负数，后续订单因购买力不足被拒。
账户净资产仍有 USD 2,021,466，说明负 HKD 是在保证金/透支额度内，不是穿仓。
