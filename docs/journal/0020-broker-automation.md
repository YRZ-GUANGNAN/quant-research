# 迭代日志 0020 · 模型→券商模拟盘自动化（2026-10-23 11:40）

## 自动化脚本

`scripts/lb_order_map.py`：把模型 v4 的美股（mom_60, k20）与港股（mom_60, k15）目标组合
映射成券商模拟盘委托，流程为「算目标 → 查每手股数 → 实时报价 → tick 对齐限价 →
预览拿 confirmation_code → `--execute` 提交」。

修复的三个真实坑：
1. **美股符号要带 `.US`**（本地代码是 `AAPL`，CLI 要 `AAPL.US`）；
2. **港股每手股数不统一**（700.HK=100、3988.HK/0939.HK=1000），必须查 `static_info.lot_size`；
3. **港股限价必须落在合法 tick**，且浮点噪声（`44.900000000000006`）会被拒，需定点格式化。

## 教训

1. **幂等性是自动化的第一要求**：下单脚本必须同时查「当日订单 + 持仓」去重，
   不能只依赖订单列表；重复下单会悄悄改变仓位。
2. **港股 tick 表仍有边界案例**（2269.HK @44.95、0883.HK @23.35 被判 bid size 错误），
   需要交易时段实测后校准（或改用市价单/对手价）。
3. **US 休市可排队**，但成交状态要等开盘核对。
