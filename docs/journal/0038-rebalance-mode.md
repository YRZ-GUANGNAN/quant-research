# 迭代日志 0038 · 目标权重再平衡模式（2026-10-23 23:20）

## 问题

`lb_order_map.py` 只会买「目标里尚未持有」的标的（幂等跳过持仓），
所以已持有的美股无法按目标权重补仓/减仓。USD 到账后无法一次性补齐。

## 新增

`scripts/lb_rebalance.py`：按目标市值再平衡
- 目标市值 = 预算 × 权重（US 预算 = 总资产 75%，HK 25%）
- 当前市值 < 目标 85% → 买；> 目标 115% → 卖
- 卖出优先释放现金，买入总额受可用现金约束（cap = cash + 卖出×0.9）

## 首次执行

```
[rebalance] us 预算 1,517,529，可用现金 117,026，持仓 29 只
[plan] 买 1 笔 NVDA.US 348 @ 212.79（约 74,051，上限 117,026）
→ submitted（order_id 1298303728486457344）
```
