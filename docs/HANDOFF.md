## 核心研究结论（含负面结论）

1. **相位噪声是回测最大的假象**：同一策略调仓日错开 5 天，验证期年化从 -0.29% 跳到 +13.24%。
   → 相位不变组合（4 相位共识 + 每日校准）把标准差从 5.04% 压到 0.53%。
2. **A 股因子结构 = 反转 + 低波 + 小成交额 + 流动性溢价**（amihud IC_IR 0.275）；
   美股样本里动量 IC≈0、波动率因子反向 → 因子有效性依赖市场制度。
3. **仓位缩放类优化全部无效**（均线择时、波动率目标）：
   乘法不改变收益符号，月胜率由收益分布形状决定。
4. **换收益源有效**：A 股-美股日收益相关性仅 0.11，拼入后月胜率 49.3%→58.1%。
5. **因子会衰减**：训练期超额 +22%，2023 后降到 +6%，2025+ 无超额（OOS 已泄露一次，仅作参考）。

## 已知坑（避免重复踩）

| 坑 | 现象 | 处理 |
|---|---|---|
| 东方财富限流 | 并发 5 只后 `RemoteDisconnected` | 已弃用，仅留适配器作备用 |
| BaoStock 全局 socket | login/logout 会踢掉其它会话（WinError 10038） | 每阶段独立会话；并发 6 会打崩服务器 |
| BaoStock 无超时 | 查询永久挂起 | `socket.setdefaulttimeout(25)` |
| 腾讯数据 | 无真实成交额/换手率 | `amount ≈ close×volume`，turnover 置 NaN |
| pandas 对齐 | `DataFrame * Series` 按列对齐 → 权重全 NaN、零交易假平滑 | 用 `.mul(..., axis=0)`；有回归测试 |
| 相位噪声 | 单窗口结论不可信 | 多相位评估，标准差 >1.5% 不采信 |
| 样本外泄露 | 2025+ 已被查看一次 | 已在日志记录，不再用于调参 |
