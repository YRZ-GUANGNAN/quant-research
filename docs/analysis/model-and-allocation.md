# 量化模型与资产配置说明

> 面向非技术读者的一页式说明。所有数字均来自仓库内可复现的回测/报告；已标注哪些是回测、哪些是模拟盘。

## 1. 一句话概括

这是一套**多市场、多因子、相位共识**的量化配置模型：
它以「A 股 60% + 美股 30% + 港股 10%」为基准分配资金，
每个市场内部用因子打分选股、按固定周期调仓，
并用「4 个错开相位」的组合对齐来抵消路径噪声；
默认再叠加 **0.70 仓位系数**（30% 现金）把最大回撤压到 -20% 以内。

## 2. 这是什么模型

| 层 | 内容 |
|---|---|
| 资产层 | 三个袖子：A 股（60%）、美股（30%）、港股（10%） |
| 选股层 | A 股：`ic_tilt` 多因子打分 + 4 相位共识，top 40；美股/港股：`mom_60` 动量，top 20 / top 15 |
| 组合层 | 等权（按打分排序取前 K），单票权重上限、成交额过滤 |
| 风控层 | 现金缓冲 2%、静态仓位系数 0.70、交易成本与滑点计入回测 |
| 执行层 | 目标快照冻结调仓周期 → 数据门禁 → Longbridge **模拟盘**执行 |

因子（A 股主力）：`amihud_20`（流动性溢价）、`rev_20`/`rev_5`（反转）、`log_amount`（小市值）、`ma_gap_60`（趋势偏离）、`vol_20`（低波）。
美股/港股：`mom_60`（60 日动量）。

**「相位不变组合」是什么**：同一个策略用 0/5/10/15 天四个不同起点并行运行，
每个相位按自己的节奏调仓，再把四份持仓相加取综合排名。
目的不是提高收益，而是**降低「碰巧在某一天调仓」带来的路径噪声**——
单相位回测的年化在 12%~20% 之间跳，四相位共识把离散度压到 ±0.5% 左右。

## 3. 资产配置方法

1. **基准权重**：按「A 股 60 / 美股 30 / 港股 10」分配资金，人民币计价；
2. **目标快照**：每个调仓周期开始时生成一次目标权重，冻结到 `state/target_snapshot.json`，
   周期内**不再按每日行情重选股**（避免执行与研究不一致）；
3. **调仓周期**：A 股 35 个交易日，美股/港股 20 个交易日；
4. **仓位系数**：`0.70` = 70% 股票 + 30% 现金（低回撤模式）；
5. **再平衡**：偏离目标 15% 以上才动手，减少不必要交易；
6. **执行**：只操作 Longbridge **模拟盘**；当前所有旧下单通道已被安全层阻断（exit 20）。

## 4. 收益从哪里来（为什么能赚）

1. **因子溢价**：A 股市场中，流动性差、短期反转、小市值的股票长期有超额收益
   （2018-2022 年 amihud 因子 IC_IR 0.277）；美股/港股用动量捕捉趋势延续；
2. **跨市场分散**：三个市场的相关性低，组合波动从 A 股单市场的 23.3% 降到 16.3%，
   回撤从 -27.5% 降到 -22.6%；
3. **相位共识**：降低「哪天调仓」的运气成分，使结果更稳定（±0.5%）；
4. **再平衡**：定期把涨多的卖一点、跌多的买一点，赚取波动收益。

**成本**：换手约 10 倍/年 × 单边 0.10% ≈ 1.0%/年，已计入所有回测。

## 5. 亏损与回撤从哪里来（为什么也会亏）

用日收益对沪深 300 回归：**beta = 0.953，年化 alpha +15.84%**。
- 亏损年份（2018 -13.6%、2022 -3.2%、2026 -5.4%）的 alpha 都是正的，
  亏损的 80%–95% 由 **市场 beta** 解释——它不是市场中性策略；
- 2025 年是唯一 alpha 明显为负的年份（-10.6%）：最大权重因子 `amihud` 的 IC 从 0.277 衰减到 0.018，
  属于**因子轮动失效**；
- 最差回撤 -26.55%（2023-08 → 2024-02），**修复用了 423 天**；第二差 -24.5%，修复 364 天。

## 6. 为什么能「收回」（回撤修复机制）

1. **均值回复 + 再平衡**：组合不是买入持有，每 20/35 个交易日重新对齐目标，
   在下跌中被动加仓、上涨中被动减仓；
2. **因子长期溢价**：只要因子溢价存在，下跌后的估值修复会被再平衡捕获；
3. **跨市场对冲**：A 股下跌时，美股/港股袖子不一定同跌，组合层面的修复快于单市场；
4. **降仓位**：0.70 仓位把最大回撤从 -27.53% 压到 **-19.98%**（代价年化 -4pp）。

**注意**：修复靠「时间 + 再平衡」，不是靠择时。均线择时、波动率目标等择时手段在本项目实测均失败。

## 8. 风险与边界（必须知道）

1. **这是回测 + 模拟盘，不是实盘业绩**；「A 股模拟盘 +238%」是 2018 年至今的历史回放，不是前瞻实盘；
2. **2025+ 数据已被多次查看**，不再算真正独立的样本外；
3. **数据质量有限**：A 股成交额/换手靠第三方近似，17 只退市股缺失；
4. **beta 0.95**：市场大跌时会跟着跌，且小盘因子在暴跌月放大跌幅；
5. **旧下单通道已全部阻断**（P0-B 安全层，exit 20），新执行链路（plan/ledger/SDK）仍在建设中；
6. 当前账户为 Longbridge 模拟盘，不涉及真实资金。

## 9. 一句话总结

> 模型赚的是「因子溢价 + 跨市场分散 + 再平衡」的钱，亏的是「市场 beta + 因子衰减」的钱；
> 它能把回撤压到 -20% 以内，但代价是年化从 15.6% 降到 11.6%；
> 长期看它是「高 beta 的小盘增强组合」，不是稳赚不赔的策略。
