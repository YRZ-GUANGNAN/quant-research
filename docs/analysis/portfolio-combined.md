## 关键发现：设计权重 ≠ 实际资金分布（2026-11-27）

### 实际分布（`scripts/capital_check.py`）

| 项 | 金额 | 占比 |
|---|---|---|
| 账户净资产 | 1,984,927 美元 | 100% |
| 已投（美股 + 港股持仓） | ~1,090,000 美元 | **55%** |
| **闲置现金（新币）** | **745,000 美元（100 万 SGD）** | **38%** |
| 其余现金（USD/HKD） | ~17,000 美元 | 1% |

袖套权重：US 40%（设计 30%）、HK 15%（设计 10%）、**CN 0%（设计 60%）**。

### 这意味着什么

1. **三分之一的钱不工作**：100 万新币以现金形式闲置，模型再好也被摊薄三分之一。
   根因是没有 FX 接口、也没有新币计价的策略。
2. **A 股为零**：设计里 60% 仓位在 A 股，实际为 0（同花顺通道未登录，只有 ASHR 代理约 7 万美元）。
3. 因此 `+13.92% / 夏普 1.01 / 回撤 −16.5%` 这个组合层结论，**是在 60/30/10 假设下算出来的，
   当前真实账户并没有跑在这个配置上**。
