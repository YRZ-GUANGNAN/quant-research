# 选型建议（2026-10-22，≤600 字）

**首选：BaoStock（数据）+ RQAlpha 6.4.2（回测主引擎）+ AKQuant 0.3.71（批量实验）**

RQAlpha 是主流框架里唯一把涨跌停、停牌、成交量参与率、税费做成内置 mod 的成熟 A 股引擎（6.4.2，2026-10-20，Python 3.10–3.14），适合当「这笔交易到底能不能成交」的裁判；AKQuant 是 AKShare 团队 2026 年新作（Rust 内核、MIT、内置 T+1/涨跌停 golden test、walk-forward），负责批量扫参与因子研究；BaoStock 免费且带 `adjustflag`/`tradestatus`/`isST` 字段。

> 最强反对：RQAlpha **仅限非商业使用**，且数据 bundle 依赖米筐服务器；AKQuant 才 0.3.x、2449 star，踩坑无人可问、API 会变——**它能加速研究，不能作为唯一真相来源**。

**备选：nautilus_trader（做事件驱动/实盘同构时）**

Rust 内核，回测与实盘同一套策略代码，v1.231 稳定、v2 RC 推进中，适合未来要多品种、要撮合精度。

> 最强反对：**没有任何 A 股数据源与券商适配**，要自己写 adapter 和数据标准化；v2 仍在 RC、API 变动大，学习成本全表最高，容易「基建半年、策略零行」。

**不选：backtrader / zipline-reloaded / qlib 当平台 / vectorbt 开源版当撮合引擎**

- **backtrader**：默认分支最后提交 2023-04-19，事实停更。
- **zipline-reloaded**：官方已转维护模式，新功能迁往 ml4t/backtest；A 股要自建 bundle。
- **qlib**：官方数据集已停用、不支持 Python 3.13，只值得抄 Alpha158 因子与 benchmark。
- **vectorbt 开源版**：限价单、杠杆是 PRO 功能，无法建模「涨停买不进」。

> 最强反对（对这一档本身）：它们文档多、教程多、上手快，**当学习材料仍是最好用的**；问题只在于别把「能跑通示例」当成「能托付实盘」。

**最容易被低估的风险：数据层的静默错误。**

AKShare 在限流或改版后会返回空表、错位行，甚至静默回落到别的 URL（issue #7444、#7431、#7301），回测照样跑出漂亮曲线；再叠加「事后前复权」的 PIT 偏差（用今天的复权因子改写半年前价格），错误不会抛异常，只会让你在实盘第一周发现那个成交价根本不存在。**先建数据校验层，再谈策略。**
